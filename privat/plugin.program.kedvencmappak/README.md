# Kedvenc mappák – `plugin.program.kedvencmappak`

Mappák és almappák a kedvenceidnek, a Kodi Kedvencek menüjében is (Kodi 19+).

## Használat
1. **Mappa létrehozása:** Kiegészítők → Programok → *Kedvenc mappák* → **+ Új mappa**.
   A program felajánlja, hogy a mappát a **Kodi Kedvencek** közé is kitűzze; onnan egy kattintással nyílik.
2. **Bármi berakása egy mappába:** bármelyik elemen (addon-mappa, videó, sorozat, könyvtári elem,
   kiegészítő, sőt a Kodi Kedvencek ablakban egy meglévő kedvenc) → helyi menü (hosszan OK / `C`) →
   **Kedvenc mappába...** → válaszd ki a mappát (vagy *+ Új mappa...*).
3. **Szerkesztés** a mappán belül, helyi menüvel: átnevezés, ikon (fájlból / az első elem képe),
   mozgatás fel / le, áthelyezés másik mappába, eltávolítás; mappánál: *Új almappa itt*,
   *Kitűzés a Kodi Kedvencek közé*, *Mappa törlése* (tartalmával együtt).
4. **Kodi Kedvencek importálása ide...** – a meglévő kedvencek közül többet is kijelölhetsz.
5. **Mentés / visszaállítás** (gyökérben): mentés fájlba, visszaállítás fájlból, vagy az előző állapotra.

Addon-mappák a mappán belül közvetlenül böngészhetők (a *Vissza* gomb visszahoz); videók, kiegészítők,
könyvtári nézetek a megszokott módon indulnak. A mappákból érdemes a Kodi Kedvencek közé tenni, a
régi, egyenként kitett kedvencek ezután a Kodi saját *Eltávolítás a kedvencekből* menüjével törölhetők.

Az adatok: `addon_data/plugin.program.kedvencmappak/data.json` (+ `data.json.bak`).
