# Network4 (privát) – `plugin.video.network4`

Nem hivatalos Kodi-kiegészítő a **Network4 / Arena4+** szolgáltatáshoz, a tulajdonos
**saját előfizetésével**.

## Szerzőség

- **Alap:** `plugin.video.arena4plus` – szerzők: **heg** és **vargalex** (GPL-3.0).
  Az Arena4Plus mutatta meg, hogyan működik a Network4 mobilalkalmazás API-ja
  (belépés, végpontok, lejátszási link).
- **Ez nem fork:** a kód újraírt (TomSzo), saját menüvel, gyorsítótárral, kímélő
  lekérdezéssel, Sportok menüvel (network4.hu/sport/collections), hibakezeléssel és
  InputStream Adaptive-os lejátszással.
- **Beépített külső könyvtárak** (`resources/lib/modules`, az Arena4Plus 1.0.3 csomagjából):
  cloudscraper (MIT), requests_toolbelt (Apache-2.0), pyparsing (MIT) – lásd `NOTICE.txt`.
- Licenc: **GPL-3.0-or-later**.

## Funkciók
- Élő közvetítések (élőben vagy az elejétől)
- Sportok: Kiemelt sportok + sportágak → gyűjtemények → videók
- Videótár (összes gyűjtemény), keresés, kapcsolat teszt

## Beállítás
Beállítások → Belépés: a saját Network4 / Arena4+ email címed és jelszavad.

Magánhasználat, saját felelősségre.
